# SmartResolve Project Management Notes

This folder contains planning notes, sprint tracking, requirements, roadmap context, and project-report support material for SmartResolve.

These notes are version controlled with the project so planning claims, implementation
status, tests, and assessment evidence can be reviewed together.

## Contents

- `project_scope.md` - final product scope and feature boundaries.
- `background_and_objectives.md` - project background, objectives, and proposal framing.
- `requirements.md` - functional and non-functional requirements.
- `requirements_traceability_matrix.md` - implementation, test, evidence, and status RTM.
- `roadmap.md` - full feature roadmap in implementation order.
- `mvp_vs_later.md` - MVP scope versus later enhancements.
- `branching_and_ci.md` - branch strategy, CI, and GitHub settings.
- `testing_and_evaluation.md` - testing, evaluation, and evidence plan.
- `proposal_context.md` - summary of the DOCX proposal context.
- `sprints/` - sprint plans, checklists, and write-ups.
- `../deployment/` - Railway setup, release, rollback, backup, and smoke-test runbooks.
- `../uat/` - UAT script, feedback form, evidence checklist, and demo material.

## Status Labels

- `[x]` complete
- `[~]` partially complete or implemented in working tree but not fully finished
- `[ ]` not started
- `[?]` needs external confirmation
