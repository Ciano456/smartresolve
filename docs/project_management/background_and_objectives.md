# Background And Objectives

## Background

Many IT teams still track support work through spreadsheets and shared email inboxes. This creates inefficient workflows, duplicated tracking effort, poor visibility, and weak accountability. In the current workplace context, requests are spread across spreadsheets and emails, which makes it harder to know what has been done, who owns a ticket, and whether important issues have been handled quickly enough.

SmartResolve addresses this by creating a centralised IT support portal for logging, tracking, managing, and reporting on support requests.

## Refined Objectives

1. Design and develop a professional IT Support Portal suitable for a real company environment and a graduate portfolio.
2. Deliver a technically challenging, well-planned, well-tested project suitable for a first-class honours result.
3. Improve Python and Django development skills through a realistic web application.
4. Automate ticket categorisation and response workflows using AI techniques.
5. Visualise key performance metrics through dashboards and analytical reports.
6. Implement secure authentication, role management, audit logging, and data protection controls.

## Proposal Framing

The proposal frames the project as a secure IT support portal with:

- audit logging
- security monitoring
- role-based access control
- secure file handling
- suspicious activity detection
- AI-assisted ticket triage
- reporting dashboards

The project should demonstrate not only helpdesk functionality, but also secure system design and cyber security awareness.

## Technical Direction

Current implementation uses:

- Python
- Django
- SQLite for local development
- Tailwind CSS
- Django templates
- Django groups for role management
- Django TestCase and pytest-django
- Microsoft Graph notification integration
- Chart.js dashboard visualisations
- CSV reporting exports

Future technical direction may include:

- PostgreSQL for production
- a shared production cache such as Redis
- scikit-learn for ticket classification
- staged production settings
