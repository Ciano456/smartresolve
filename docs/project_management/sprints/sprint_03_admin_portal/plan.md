# Sprint 3 - Admin Portal

## Goal

Allow admins to manage users from the SmartResolve UI.

## Tasks

- admin portal landing page
- user list
- create user
- edit user
- activate/deactivate user
- assign groups
- admin-only access control
- user management tests

## Deliverable

Admins can manage user accounts, roles, and active status without relying only on Django admin.
