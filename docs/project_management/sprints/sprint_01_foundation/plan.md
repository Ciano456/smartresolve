# Sprint 1 - Foundation And Repo

## Goal

Make the project safe to build on.

## Tasks

- clean project structure
- confirm app boundaries
- set `AUTH_USER_MODEL`
- clean settings structure
- add `.env.example`
- clean root URLs
- set up GitHub repo workflow
- create `main` and `develop`
- add GitHub Actions CI
- protect `main`

## Deliverable

A stable Django project foundation with custom user setup, migrations, settings, docs, and CI ready for future feature work.

## Strict Exit Criteria

- foundation is stable
- custom user is locked in
- migrations are committed
- settings are cleaned
- CI exists
- setup docs exist
