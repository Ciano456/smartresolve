# Sprint Index

## Sprint Structure

Each sprint folder contains:

- `plan.md` - sprint goal, tasks, deliverables, and feature done checklist.
- `checklist.md` - trackable sprint checklist.
- `writeup.md` - sprint progress/report write-up.

## Standard Feature Done Checklist

- [ ] model ready

- [ ] admin registered
- [ ] form created
- [ ] view created
- [ ] template created
- [ ] permission check added
- [ ] test added
- [ ] merged via PR
